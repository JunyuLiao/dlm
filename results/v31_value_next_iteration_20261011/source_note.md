# Selector source note

The control's qblock selector ranks eligible physical KV64 tiles by worst-row native prefix attention mass, with a fixed per `(head, 128-row query block)` budget, mandatory suffix/protected tiles, stable tile-id ties, and no value-direction score. V2 instead scans tiles in native order with a running projected Gaussian32 output and preserves running mass on skips; its threshold is global and its map is not a fixed quota. The new fixed-budget arms use the control mass map as the anchor and allow value-direction swaps only inside the same per-qblock budget. Online arms use V2's projected residual score; full arms use final-output omission score on available value summaries, while the true full-dimensional score is used only in the offline gate. C_gate is a fixed-budget row-weighted rank, not a multiplicative risk. Intersection arms use the support intersection of the exact control map and V2 map.
