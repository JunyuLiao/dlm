## One prospective training-free readout proxy

Only past/current information selects supports. Previous native winner and its
strongest other-token competitor, processed logits,entropy,stable-position mask
and native temperature are available before the affected call. Actual argmax
comes from native state, never topk indices as a winner substitute.

For layer29 actual current bias b, use the linear output-projection and LM-head
coefficient for the PREVIOUS winner/competitor pair. Include previous softcap
derivatives (1-(z/c)^2), if configured, and current native temperature scaling.
This exactly represents the chosen fixed linear readout component; it omits
post-attention RMS normalization,MLP/MoE,final normalization and intervening
Jacobians. It is an explicitly approximate previous-pair projection, NOT an
exact influence oracle,downstream entropy gradient,or sign guarantee.
No model/MLP/tail recomputation is allowed. Weight gathers/linear projections
are counted separately as diagnostic operator work.

Restrict readout choice to the CE-error/mass-matched feasible pool. Lexicographic:
minimize projected crossings below0 among previously stable positions; maximize
previous-entropy-weighted projected pair-margin increase; minimize current error;
then support hash. Previous entropy weights normalize by max(sum,1e-12).
Temperature-adjust the previous pair margin as a proxy base. Record empty
protected sets and tiny/zero native biases; CE fallback is explicit. The rule
has no learned controller or fitted parameters and is distinct from previous
margin-weighted-bias,high/low alignment,Response/A1,Gaussian32 or C-gate.

The finite bank may contain different supports the rule does not select. Study
mass distributions,actual bias norms/cosines/localization,entropy concentration,
past margins/stability,and complete-canvas changes separately. Current A logits
from a separate reference model call are diagnostic outcomes, NOT free online
selection information. Post-pulse entropy/history and future winner/motion are
outcomes/mediators only, never predictor inputs.
