# Process-matched native value-refinement development

Frozen overlay source: `28714b4a`; frozen base method source: `79c994ca`.
The deployment recipe and every file hash are in `protocol.json` and
`receipts/source_fingerprints.json`. Parent independent-process AIME scores
remain interpretation-held and are excluded from this campaign.

Same previously examined development cohorts: AIME26 30 problems x3 seeds
(90 trials,10 engine blocks), LongBench-v2 64 (8 blocks), MATH500 100
(10 blocks), RULER128K 104 (13 blocks). This is exploratory development,
not held-out confirmation. No scoring outcome changed the candidate set.

Every problem is run with a V31 control, all four candidates in a rotated
order, and another V31 control in the same warmed compiled engine. Control
bookends must be output/hash/N/C/T-identical, and any inactive candidate must
match its common control. All four workloads must first pass sparse exposure,
fixed-budget, native-path, control-bookend and official-scorer smoke checks.
The original one-cell two-engine qualification passed and is bound under
`receipts/process_qualification/`.

Candidates: full-V bounded mass-neighbor swaps; cached residual with directional
trust; raw cached residual as a mechanistic baseline; swaps plus directional
trust. Changes are restricted to GLOBAL layer29. Prefix budget K is fixed per
query head/Q128 tile:128 long-workload KV64 blocks,27 on AIME/MATH. Common
mandatory boundary/canvas blocks, dense bootstrap/prefill and carry are counted
separately. Native sampling and stopping remain unchanged.

Dense FULL fix51994, dense PIECEWISE and all-kept FA4 remain fresh, separately
named reference paths. Their engines are independent; unresolved process-level
numerical variation limits numerical-parity claims against those references.
The primary incremental candidate-versus-V31 comparisons share an engine.
Report problem/task-cluster intervals and an additional process-cluster
sensitivity analysis; neither establishes noninferiority.

Raw paired records and private completions remain immutable in shared attempts.
Per-arm exports identify the exact raw attempt/ordinal and normalize only the
study-arm label. Export completion requires the shared-attempt completion
marker. Failed attempts are retained and a resume creates new attempt numbers.
Each successful shared shard contains all candidate/control pairs.

Clean timing is paused. Audit wall times and fewer denoising calls are not
measured speedups. Extra selection/correction work is reported explicitly.
Full503 promotion retains the predeclared all-workload accuracy/N/tail gates
and requires a separate frozen protocol.
