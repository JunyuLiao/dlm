# Pre-answer cost selection rule

Frozen before any usable v20 timing or scored answer. The captured inputs are
development inputs; this is an execution screen, not a quality selection.

Use the existing qualified Hopper and generic Triton consumers. Compare each
scope's P0 R2 and matched B at the same captured states on each GPU. Select the
consumer with lower geometric paired complete-call cost across available states;
show dispersion and host-specific values. Never combine absolute host times.
Numerical, native-mask, state-restoration or timing-integrity failures disqualify
the affected evidence. Large native bracket drift (>5%) is marked unstable and
cannot establish a small speed benefit. Preserve every failed/missing cell.

All-layer routing is primary if qualified and it shows repeatable forward
headroom. If only GLOBAL routing has headroom, choose GLOBAL. If neither does,
use the cheaper qualified common scope for the bounded seven-arm answer pilot,
label the operating point negative, and still close the requested comparison.
Use equal family weights for cross-family summaries; also show every family.
RULER's short actual canvases and AIME's short prompts remain explicit strata.

P0 is the moderate transferred policy. Select P1 only when its increased physical
skipping produces a repeatable complete-sequence cost reduction under the same
chosen scope/consumer. Otherwise retain P0. Publish exact thresholds and achieved
QK/PV work; parent RULER T50/T60 names are not achieved AIME/LB targets. No answer
quality is consulted, and no additional threshold proposal is introduced.

N4 screens are preliminary. Retain longer reached sequences and whole-step
boundaries for the selected configuration before claiming amortized execution
benefit. A sum of directly timed calls and an outer replay span containing
fixture restoration remain separate quantities. Per-call event synchronization
is excluded from clean adaptive answer timing. A prepared-support diagnostic
does not constitute a deployable method or an exact same-QKV full forward when
different anchor arithmetic changes downstream states.
